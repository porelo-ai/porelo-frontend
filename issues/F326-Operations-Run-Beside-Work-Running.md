# F326 — Operations Run Beside Work Running

**Status:** Implementing.

**What must be true.** The status line's count of operations cannot be read as a count of work running.

**The operator:** accepted, with `2 running, 2 finished` suggested for the status line.

`4 run` in the status line counts the operations this window ran on the machine, finished ones too, and the work list
beside it says `Running (1)`. A person in a walk took the two for one count that disagreed; they count different things.
