# F150 — The Person's Tunnel Brought Up From The Interface

**Status:** Idea.

**What must be true.** The person brings the VPN tunnel to a host up and down from the interface,
with one confirmation for the root rights it needs, instead of importing the offered `wg-quick`
file into their own WireGuard by hand.

## Why

[F140](README.md#f140) only shows the tunnel's settings and offers the file, since the interface
runs without root.
